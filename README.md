# 🚜 Multi-Purpose Water Spraying Robot

A microcontroller-based agricultural robotic platform engineered for automated crop irrigation, dust suppression, and emergency fire response with mobile telemetry.

---

## 🌟 Key Highlights
- **Locomotion Subsystem:** Differential 4WD drive controlled through an L298N H-Bridge motor driver.
- **Automated Pumping System:** High-pressure 12V submersible diaphragm pump controlled via optocoupled relay channel.
- **Wireless Telemetry & Control:** Wi-Fi Socket connection handling remote driving commands and status flags.
- **Emergency Override:** Flame detection sensor trigger capable of automatic water discharge for fire mitigation.

---

## 🛠️ Hardware Architecture
- **Control Unit:** ESP32 Microcontroller
- **Motor Driver:** L298N Dual H-Bridge Motor Driver
- **Pumping Mechanism:** 12V DC Water Pump with 5V Relay Module
- **Sensors:** IR/Flame Sensor for emergency fire detection
- **Power Source:** 12V Li-ion Battery Pack (with step-down buck converter for 5V MCU logic)
